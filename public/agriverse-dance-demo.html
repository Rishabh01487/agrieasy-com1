How this works: The animation uses a sprite sheet containing 8 different dance poses (arms down → right arm up → both arms up → left arm up → arms out → hop → lowering → neutral). CSS steps(8) cycles through one frame at a time, creating a flipbook effect. The character's actual arms and body move because each frame is a separately-rendered pose — not just a CSS transform on a static image.
